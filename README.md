# Tournament

ガンダムカードゲームを初期対応タイトルとする、独立した大会運営サイト。

## 作業先

- ローカル: `F:\MAMP\htdocs\tournament`
- GitHub: https://github.com/fabtcgjp/tournament
- `site9` ではなく `tournament` をプロジェクトフォルダ名として使用する。
- サービス名称・公開ドメイン・公開パス・実装技術は未確定。

## 目的

プレイヤー、主催者、ジャッジが、募集から大会終了まで利用できる大会運営環境を提供する。大会当日の操作を広告で妨げない。
